Critérios de Suficiência de Dados

A validação de Dados Suficientes para o cálculo do risco climático de cada estação meteorológica depende diretamente da quantidade de horas com medições válidas no período de 7 dias:

Período total analisado (7 dias): 168 horas
Mínimo exigido para análise válida: 96 horas (≥ 57,1%)
  • Estação Validada (≥ 96 horas): Possui amostragem horária suficiente de temperatura e precipitação para calcular com confiabilidade o Índice Térmico, o Balanço Hídrico e a classificação de risco.
  • Dados Insuficientes (< 96 horas): Quando uma estação registra menos de 96 horas válidas no período (por manutenção ou falha de transmissão), ela é automaticamente classificada como Dados Insuficientes / Não Analisada para evitar distorções no alerta.
